# Agent Undercover — project-wide instructions

- Ship a normal-browser product conforming to the current Open Agentic Web MVP specification. Track the upstream spec/runtime commit and evidence. Peer network definitions run locally in the caller browser.
- Targets are owned synthetic fixtures first. External targets need explicit operator authorization and an opt-in compatible adapter. A public URL alone grants no testing permission.
- Runtime models may generate requests and explain results. Deterministic code owns consent, tool authorization, effects, budgets and findings. Never claim general security certification.
- Keep canary values and oracle ground truth out of spy prompts. Canary secrets are synthetic and not stored in public artifacts. A canary known to the attacker is an invalid leakage test.
- Use real runtime instrumentation at supported seams. Keep observed effects distinct from assistant promises and requested actions. Test errors and timeouts are inconclusive.
- BYOK secrets stay in memory and only reach the selected inference endpoint. Reports exclude tokens, signed URLs and private content. Do not run peer-provided executable code in v1.
- Preserve unrelated work and upstream licenses. Use small readable modules and meaningful regression tests. Update checkpoints after milestones or 30 minutes.
- No decorative footer, attribution bar, signatures, badges or powered-by strip. Record legally required notices in source/reference files. Use short clear product language.
