# Agent Undercover — voiceover script

Record this in the entrant's own voice. Do not use AI narration for the submitted video. The silent cut is a picture lock; record against it in a quiet room, then mux the WAV into the Remotion project.

Target length: **66.5 seconds**. Read at a natural, unhurried pace. If a line runs long, trim words rather than speeding up unnaturally.

| Time | Line |
| --- | --- |
| 0:00–0:05 | Before I connect my agent to another website, I want to know which boundaries actually hold. |
| 0:05–0:13 | A friendly demo only shows the sentences. Agent Undercover shows the effects: a leaked codeword, an unauthorized discount, a booking finalized without approval. |
| 0:13–0:19 | It starts with one owned synthetic fixture and one exact published network. |
| 0:19–0:25 | The target origin is contacted only after explicit consent. The request is read-only, and the key, canary and action arguments stay out of it. |
| 0:25–0:33 | In the weak fixture, the target reply contains the exact per-run canary. The deterministic oracle confirms the disclosure. The value is session-only and replaced in every export. |
| 0:33–0:43 | The repair is a configuration change, not a prompt rewrite. The same three requests rerun against version two; the compare view keeps both hashes and reports not observed. |
| 0:43–0:52 | Host consent is separate from business approval. A model claim is only text. Version two requires a fresh one-use token bound to the proposal. |
| 0:52–0:58 | The workbench is also a published agent site: a manifest, a data-only explainer network, a runtime and a normal interface. |
| 0:58–1:06 | Owned fixtures. Deterministic oracles. Execution in the caller's browser. Test the boundary before you trust the agent. |

## Delivery notes

- Say “canary” as a test value, not a bird; the visual shows the exact synthetic value.
- “Not observed” is a finding, not a claim of security. Keep the qualifier.
- Do not add “certified,” “secure,” “production-ready,” or a live-model claim.
- Leave a beat after “boundaries actually hold” and before the outro.
- The video is a fixture demonstration. A live-model segment must be recorded separately and labeled if one is added later.
